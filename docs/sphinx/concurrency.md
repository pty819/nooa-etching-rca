# 动态子研究、共享预算与生命周期

## 不预设固定物理角色

主agent依据证据派生具体任务，例如“检查参考腔共模”“复现一个估计器变换”“检验某支路的跨step稳定性”。没有把RF、气路、背氦永久写成几个固定角色。每个分支仍是具备通用代码能力的研究员，而不是只能调用窄工具的分类子程序。

`ResearchManager`把原生QueueManager的spawn、channel和event与真实独立进程组合。QueueManager本身只调度异步任务，不会自动创建OS进程、目录、SQLite或恢复策略；这些是本项目的生命周期代码。

## 隔离、任务传递和结果接收

分支有独立host、科学worker、workspace、NOOA历史、trace、摘要器和审查目录。公开input只读共享，父任务提供的种子证据复制进自己的目录，并记录来源与哈希。子任务不默认继承整段父会话，必须在task和证据包中说明需要解决的问题。

结果通道携带分支id、状态、审查状态和有界摘要，主研究可以读取完整结果再综合。`read_branch_result`为主研究重写产物路径，加上分支命名空间；旧mission的报告不能因同一分支恢复失败就被误当成本次新结果。

专家消息和父agent指导保留不同source。运行中的Web消息送入指定方向inbox，控制协程再送入原生事件通道；模型在后续上下文看到指导，不代表正在进行的同一次模型生成能即时改写答案。

## 状态机

```{mermaid} diagrams/branches.mmd
:caption: 分支是可恢复的持久方向。completed表示执行完成，不隐含review_status为passed。
:alt: 分支从queued、starting到running，可完成失败取消或中断；每个终态都可显式恢复为新mission。
```

同一活跃task文本会去重；默认每轮最多八个新分支、两个分支host活跃。当前只允许主研究直接派生，子分支不能递归派生。不同分支失败互不销毁；主研究仍应说明缺失方向对结论有什么影响，而不是把“父任务成功返回”当作所有子研究都成功。

单独取消先写取消标记并等待协作退出，再在宽限后核对并清理后代进程。整轮停止会关闭协调器与全部子任务。进程创建被shield并在取消时收回创建结果，避免取消恰好发生在启动边界产生未登记子进程。强杀或父host丢失会留下interrupted，供显式恢复。

`wait_research`等待上限60秒，可多次调用；非终态结果的observed_at仅表示查询时间，不能视为科学进展。长期无结果仍受超时和预算约束，不能把更新时间戳用作“有新证据”的理由。

## 两个并发上限和一份预算

```{mermaid} diagrams/budget.mmd
:caption: 原生Broker限制每次provider尝试；SQLite账本负责跨进程token预留和结算，两者职责不同。
:alt: 所有模型调用先原子预留token，再获得原生准入；成功、未知失败、派发前拒绝和重试分别结算并向UI发布快照。
```

分支并发限制研究host数量，模型并发限制实际请求数量。父研究、子研究、自动摘要、Predict审查、Reflexion判词、reply正文都通过同一mission的原生AdmissionControl/Broker。同步模型调用被禁用，以避免绕过异步准入。

默认最大模型请求并发2、请求次数256、总token额度4000000。一次逻辑调用预留两倍窗口以覆盖配置的一次SDK重试；每次原生许可都被计数。正常成功按供应商usage结算，先前重试缺失usage则按窗口补估。未派发的准入拒绝token计为零；失败/未知用量保守扣预留；退出子进程未结算预留转为估算。

由此可能在仍显示余额时拒绝下一次大请求：余额不足以覆盖保守预留，并不表示供应商真的消费了全部余额。UI数字是研究预算账本，不是精确供应商费用。不同会话/独立轮次没有部署级共享总配额；若需要全账户限流或费用控制，必须再增加部署级服务。

## 恢复边界

resume保留分支身份与历史，但使用新mission、重建运行对象和内存。兄弟分支已完成结果可继续使用，不需要从头派生。当前实现是单主机进程协调，不是分布式任务队列、远程worker调度或跨机器租约系统。

原生Broker连接配置保存到权限0600的本地临时文件，任务结束后移除；原始凭据不放入任务包。文件、进程、预算和事件之间没有全局事务，必须依靠mission匹配、进程身份和审计记录解释异常边界。
