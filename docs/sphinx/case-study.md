# 历史研究复盘：命中了什么，遗漏了什么

## 案例来源与证据等级

此章复盘已有五轮研究：三轮自由计算，两轮只讨论。研究agent获得75次目标加工与15次同期参考的公开发现集，未获得生成器源码、test或隐藏状态。组织者参与过仿真构建与专家反馈，因此不能称为严格盲评。

以下数值来自本机历史产物，并在文档编写前用公开特征重新核对；原始对话、数据库和trace不随公共仓库发布。读者可根据本仓生成器复现同类场景，但不能把这个汇总当成独立第三方评测。较早的feature-only分类夹具与最近仅统计run的并行验收，均不是本章的五轮RCA研究。

## 生成器的真实设定

| 隐藏名义参数 | 正常时段1 | 严重异常时段2 | 维修后时段3 |
|---|---:|---:|---:|
| 边缘泄漏系数，sccm/Torr | 0.010 | 0.380 | 0.018 |
| 边缘热接触因子 | 1.00 | 0.42 | 0.72 |

逐run另有小幅随机扰动。时段3泄漏大幅降低但仍高于正常，接触也只部分恢复。参考腔不注入这组故障。两腔共同的环境/标定事件用于制造非根因变化。这里读取真值是宿主后验核查，不是agent自己的发现，也没有把这些答案追加回历史研究上下文。

## 它确实发现了具名特征

下表为公开目标run中，已提取特征按业务时段再取均值。整步特征与后续裁窗稳态量不同，不混用统计口径。

| 特征 | P1 | P2 | P3 |
|---|---:|---:|---:|
| he_edge_pressure_torr__step_04__mean，Torr | 10.0034 | 7.9204 | 9.9995 |
| he_edge_inlet_sccm__step_04__mean，sccm | 0.0989 | 3.0000 | 0.1773 |
| he_edge_valve_pct__step_04__mean，% | 3.2987 | 100.0000 | 5.9174 |
| heater_z5_power_w__step_04__mean，W | 27.8611 | 32.1671 | 29.2025 |
| he_edge_inlet_sccm__step_08__p05，sccm | 0.0942 | 2.9914 | 0.1726 |

step04为etch_1，step08为etch_2。历史筛选表实际将边缘He流量的mean、min、max、p05等跨step特征排到候选前列；这些记录有sensor、step_name、statistic、unit与批次层检验，不是只有可视化图。极大的标准化效应部分来自平台期极小的组内方差，不能按排名大小直接给根因置信度。

agent进一步发现：异常不只在RF点火时出现，多个无RF加压步骤也有边缘欠压；中心背氦压力接近10Torr，参考腔未出现同样的退化。维修后压力恢复，但供气需求和部分边缘加热功率仍偏离基线。它把这些组织成设备现象，而非只罗列高权重列。

## 与真值的一致程度

| 问题 | agent最终可接受结论 | 后验判断 |
|---|---|---|
| 异常在哪里 | 边缘背氦支路欠压、供气/阀位平台 | 命中主要可观测异常区域 |
| 是否就是泄漏 | 物理泄漏是候选，但测量/控制共因未排除 | 与真值兼容，未完成唯一因果识别 |
| 维修是否完全恢复 | 压力恢复而工艺与部分控制需求仍有残留 | 与部分修复设定一致 |
| 是否还原接触退化 | 真实接触状态不可见，不能从恒定估计夹持力排除 | 没有独立确认第二隐藏机制 |
| 能否确定漏点/部件 | 仍需独立取压、标定及有隔离边界的保压/检漏 | 没有完成部件级定位 |

所以可以说异常支路和特征发现成功，不能说完整还原两种隐藏原因。正确的不确定性也是结果的一部分；为了“命中真值”强行把未观察的接触系数写成已确认，会降低研究可信度。

## 迭代中实际修正的内容

| 初始错误或过强判断 | 后续处理 |
|---|---|
| prepare平均SP约2.5被当成独立固定设定点 | 回看实际0/10指令和联锁，撤回该证据 |
| OPLS训练期去正交、预测期漏变换 | 重写一致变换并做合成检查，撤回旧Q² |
| 无序unique结果被称为top榜 | 显式排序，检查目录白名单与单调性 |
| 三状态簇渐近p≈0被用作剂量论证 | 枚举六个排列，改为双侧精确p=1/3 |
| 把边缘55.3%残留写成恢复 | 分开分母口径，改为44.7%恢复 |
| error、demand、valve被当多份独立证据 | 承认同一闭环依赖，双表独立性未知 |
| 已测电气/轨迹稳定被扩展为接触无异常 | 限缩为观测，真实接触仍未决 |

专家主要对已提供的数字、代码和推理进行排除，没有凭空提供一份完整故障清单。不过专家知道生成方法，因此这种迭代仍有非盲组织者影响。

## 后验检查仍发现遗留错误

第三轮文字将P2稳态压力写为 `7.9204 ± 0.035 Torr`，对应保存表 `steady_etch1_summary.csv` 的 `PV_sd` 却为 `0.2035`。在没有新的统计口径说明前，这两个表达不一致。文档保留这个问题，不悄悄修改旧报告或把方向命中当成全部数字已正确。

这也解释了为什么新架构增加结构化EvidenceRef和确定性门禁：可明确引用的保存表数字可以被程序复核。但自然语言里没有结构化引用的误差项、算法实现和因果解释仍可能漏检。新门禁并未自动把旧五轮报告追溯升级为“全量通过”。

## 后续科学评测应怎样做

下一阶段应冻结多个未公开场景、独立lot与保留集，在不接触生成器答案的提示作者/评审组织下比较：异常区域定位、无关特征误报、第二机制发现率、错误根因的撤回能力、可区分实验质量、总tokens和耗时。应同时报告未决结果，不能只展示最漂亮的一个泄漏案例。当前50项工程测试和并行计数验收不足以替代这项工作。
