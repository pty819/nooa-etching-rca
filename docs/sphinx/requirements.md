# 需求、业务边界与验收口径

## 要解决的问题

在相同recipe下，目标腔经历正常、明显恶化、维护后改善但有残留三个业务时段。输入是大量传感器时间序列及其按step提取的特征，其中混有恒定设定值、无关噪声、冗余读数、闭环控制器输出和真实异常。系统需要帮助设备专家从这些信号中形成带数学依据的怀疑方向，而不是把分类标签预测正确当作部件定位完成。

现有人工方法是**两两label做OPLS筛选，再用PCA观察**。本项目保留这一可复现基线，但研究agent可以提出更适合问题的统计或时序方法。三个业务比较为1↔2、2↔3、1↔3；它们与训练/开发/测试划分是两条独立轴。后者控制研究泄漏，前者描述设备状态。

设备专家的协作特点是：对于若干有数字、代码和反证的候选方向，能较快排除不成立的解释；要求专家凭空提供完整故障清单则不现实。因此agent负责产生、计算和修订候选，专家主要审查已形成的证据。系统不强迫凑满十个根因，也不能把专家的质疑当成已经验证的设备事实。

## 用户旅程

1. 选择或生成固定recipe数据，创建独立研究会话。
2. 提出时段比较问题，agent先核对schema、目录与样本范围，自主编写实验代码。
3. 用户实时看到模型返回的推理、完整调用状态、真实执行输出及阶段性中文说明。
4. agent可以按当前证据派生独立分支，获得结果后合并，也可取消低价值方向。
5. 专家对主研究或指定分支追加质疑；后续计算沿同一历史继续。
6. 候选经确定性校验和结构化审查后交接；不足、耗尽和中断均明确显示。
7. 关闭浏览器不取消研究；刷新重放记录。单独恢复分支时不重新运行父任务。

## 功能需求

| ID | 要求 | 验收含义 |
|---|---|---|
| R01 | 200通道、11step的物理约束时间序列 | 有真实波形、step边界、目录与从波形计算的特征；不是只伪造特征宽表 |
| R02 | 固定recipe与三业务时段 | 指令、时长、采样网格及recipe哈希一致；反馈输出允许响应故障 |
| R03 | 通用代码自主研究 | 可写任意科学Python、保存脚本与运行；不只暴露固定筛选工具 |
| R04 | 中文报告与多模态证据 | 有人话解释、候选状态、反证、表格与实际图片；不是只有PCA图 |
| R05 | 多轮和定向指导 | 保存用户消息与来源，运行中送入后续上下文；不丢失已保存资产 |
| R06 | 数值引用和范围检查 | 文件存在、列与行、聚合、recipe和公开run集合可明确复核 |
| R07 | 审查与定向修订 | 审查问题有定位，修订有上限，保留旧证据，不把未通过写成通过 |
| R08 | 局部原生Reflexion | 有界、只读、保存实际判词；函数返回不自动代表满意 |
| R09 | 动态并行研究 | 独立进程/工作区/存储/身份；兄弟分支失败隔离 |
| R10 | 所有请求共享预算 | 包括研究、子任务、摘要、审查、正文和重试，而非只限制主研究 |
| R11 | 实时交付与可恢复事件 | 普通工具完整执行，正文独立流；SSE序号续传和请求ID去重 |
| R12 | 可复现与可审计 | 代码、失败、修订、输入哈希、快照与审查状态保留 |
| R13 | 详细公开设计与自动文档发布 | Sphinx严格构建、Mermaid实际渲染、GitHub Actions与Pages可访问 |

每条要求对应的源码、测试和限制见[追踪矩阵](traceability.md)。R04已有报告能力，但“每次内部重算必须输出完整传感器名/旧值/新值/修改原因”的严格字段尚未实现；不能因需求存在而把它写成已满足。

## 非功能需求与明确限制

**可靠性**：重复动作由原生LoopGuard提醒/终止；错误运行不能被当成成功。预算结束时保留可交接的文件与检查点。**可解释性**：区分观测异常、统计关联、机制候选和已证实部件。**资源**：默认两个活跃子分支、两个模型请求并发；限制按单轮及其子任务共享，不是整个部署的账户级总配额。

**运行平台**：自由代码worker当前要求macOS。Linux可以构建文档、运行跨平台测试与仿真，但没有已实现的等价受限执行后端。**安全边界**：科学worker限制不等于可信编排主机对恶意agent的完整沙箱。**测量真实性**：数据是降阶仿真，不是Lam/AMAT实测数据或标定数字孪生。

## 不属于本次交付

不把跨案例知识库、MCP设备手册检索、视觉模型审图、递归无限子agent、现场设备操作、自动维修验收或生产告警纳入已实现能力。Pages只发布文档，不托管有密钥的研究服务。不以界面联通测试代替科学正确性评测。

## 数据与报告的成功标准

成功不只是一个HTTP 200或一张分离明显的散点图。一个可复核候选至少能指明观察对象、step/样本范围、已保存数值、反向证据、替代解释与下一项可区分检查。若数据只能识别到边缘背氦支路，正确交接可以停在这个层级；不能为了命中生成器答案而越过观测边界。
