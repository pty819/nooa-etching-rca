# 固定配方刻蚀仿真与特征生成

## 模型定位

当前数据生成器是**通用ICP硅刻蚀的降阶模型**。目标是保留控制、热、气体和加工顺序之间有意义的耦合，形成既有真信号又有伪相关的研究问题。它不是生产配方、完整等离子体求解器、IEDF计算、三维CFD或厂商设备的已校准数字孪生。

Lam与Applied Materials公开产品材料为变量分离提供了机制层参考：物种、离子通量与能量应分开；排气流导与壁面副产物库存不可用总压单独替代；径向传热、ESC和边缘状态值得保留。具体速率系数、时间常数、腔体体积代理与噪声幅度是本项目假设，不是从产品文案反推出的实测参数。来源及适用边界见[参考材料](references.md)。

## 完全相同的recipe

11个步骤共356秒，默认0.5秒采样，每个run为712个点。步骤边界使用左闭右开时间区间；每个固定时长必须能被采样周期整除。用户要求的两次升温/稳定/加工/降温，以及释放、离开腔室过程均有对应step。

完整气量、13.56MHz RF频率、CW模式、六区温度偏置、10Torr背氦设定、1200V夹持指令、冷却条件均在 `recipe_document()` 里。规范化JSON生成SHA-256并写入run元数据。验证器不仅比较recipe_id，还比较时序和被标记为recipe指令的完整曲线。

PCV开度需求与背氦流量需求是**反馈输出**，应随硬件状态改变；把它们锁死才会破坏故障可观测性。背氦压力设定的实际应用受夹持联锁影响；RF期望指令也可能因联锁延迟实际点火。固定recipe不等于所有观测量逐点相同。

## 动力学组成

一阶响应使用稳定的指数更新：

$$x_{t+\Delta t}=x_*+(x_t-x_*)\exp(-\Delta t/\tau).$$

RF匹配网络分别计算source和bias响应、前向/反射/输送功率与C1/C2调整。C1/C2在当前模型中是以pF表示的**可变匹配电容**，不能写成电感通道。源与偏置共同影响加工，但没有把二者简单相乘就称作等离子体物理。

气路用MFC、管路滞后、PCV与有效泵速描述总压和置换。`Chemistry.transport()`分别追踪分压代理与活性物种；`products()`用气相/壁面两个库存的隐式更新，检查生成、副产物排出和库存变化的平衡。库存单位是无量纲代理，不得解释成已标定浓度。

背氦控制器根据压力误差形成受限供气需求，压力随供气与泄漏导通变化。在简化稳态下可写为 $Q\approx C_{leak}P$，但观测供气readback不是直接漏率测量。ESC六区与晶圆中心/边缘传热耦合，边缘换热还受隐藏接触系数影响：

$$G_{edge}=c_{contact}\left(2+\frac{5P_{He}}{P_{He}+4}\right),\qquad
q_{edge}=G_{edge}(T_{wafer,edge}-T_{ESC,edge}).$$

这些方程展示实现中的机制假设，不是生产识别模型。接触系数与晶圆真实温度不进入公开传感器；恒定夹持力估计值不能排除接触改变。

## 场景、噪声与伪特征

默认90次目标加工和18次同期参考加工，每lot五片，三时段分配为目标35/25/30。每个时段的最后一个lot留为test，倒数第二个为dev，其余为train，公开发现集因而为75目标和15参考（目标30/20/25，参考6/4/5）。参考腔每lot一个run，与目标腔保留固定硬件指纹，不能把所有A-B原始偏差都视为新故障。

A腔时段2注入边缘背氦泄漏与接触退化，时段3只部分恢复；B腔不注入这一故障。两腔同时加入环境变化与冗余温度仪表偏移，作为共模和标定干扰。另有非活跃通道、冗余/估算量、有限值异常和短时动态，使单变量高权重并不自动对应独立根因。公开仓库含这些构造逻辑，因此严格盲评必须在运行与组织上另做隔离。

## 特征的精确定义

每通道每step提取10项：mean、总体std(ddof=0)、min、max、线性插值p05/p95、rms、对时间的线性slope、末个有效值减首个有效值delta、missing_fraction。200×11×10=22000列。NaN先变为null；slope使用有效时间点方差与协方差。所有值来自保存观测，而非根据label直接填特征。

默认特征包含step内所有点，所以启动、联锁和切换会影响均值。研究者可重做稳态窗，但须保存裁窗标准、有效样本数、单位和版本；不能把重算稳态量与原始整步mean混为同一统计口径。
