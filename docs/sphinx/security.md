# 数据边界、公开发布与运行安全

## 威胁与信任假设

这个demo主要防止研究代码误读隐藏数据、修改其他方向资产、继承模型凭据、从网络取回答案，或把产物路径变成任意主机文件读取。模型提示、公开数据中的文字和父任务提供的材料均不能自动提升为系统指令。

可信编排主机持有凭据并运行NOOA；科学worker处理自由Python。当前实现不是多租户公网服务，也没有完整的恶意agent沙箱认证、远程权限系统或用户账户隔离。

```{mermaid} diagrams/trust.mmd
:caption: 当前信任边界。安全限制主要位于科学worker；公开源代码本身不具备盲评保密性。
:alt: 凭据和隐藏真值保留在可信host，科学worker使用白名单环境、限制写入及读取并禁网；公开源码需要另行隔离才能盲评。
```

## 科学worker的具体限制

`PythonWorkspace.profile()`要求macOS sandbox-exec，其他系统明确失败，不静默退回无限制执行。网络被拒绝；写入限制在本方向workspace，保留/dev/null例外；Python采用隔离启动与显式环境白名单，依赖线程数及缓存路径在工作目录设置，不继承父环境里的API key。

文件读取规则针对 `/Users` 与当前公开input的父案例树，允许系统、Python依赖、公开input及本workspace所需路径。**这不是所有POSIX路径的deny-all读取策略**，不能据此承诺任意位置的主机文件都不可读。科学代码还可运行子进程，因此进程超时/取消必须清理后代，不能只关一个通信管道。

NOOA编排环境仍在host；公开工具边界、框架限制与科学worker共同降低误操作风险，但没有提供“恶意模型完全不能触及host”的完整保证。将服务部署到公共网络前，应换成经过验证的容器/虚拟机或远程执行后端，并重新验证凭据、文件与任务权限。

## 数据与产物限定

发现工作区只导出train/dev的目标与参考run、曲线、量测及目录，test和truth.private不进入input。EvidenceVerifier再检查公开run范围与固定recipe。artifact下载规范化路径，拒绝目录穿越和逃逸符号链接；分支命名空间要求真实注册目录和marker，不允许以任意路径冒充分支。

种子证据复制进分支，避免可写共享文件导致互相覆盖。快照复制忽略符号链接和缓存；原始报告与修订分别保留。API本身不返回模型密钥或Broker认证配置。写请求的Origin/header检查不能替代身份认证，所以服务默认只监听127.0.0.1。

## 凭据管理与模型数据发送

自定义provider使用本地 `.env` 的FACTOR_API_BASE、FACTOR_MODEL、FACTOR_API_KEY等配置，真实key不写在命令参数、文档或源码。可选Hermes导入必须显式提供SSH目的地址，结果仅写本地忽略目录 `.secrets`；不公开默认内网地址。API调用会向所选模型服务发送任务、上下文与工具结果，部署者应先确认该服务的数据接收范围。

Broker认证配置是临时0600文件，任务结束移除。任务包只传私有配置引用，不传明文API key。token日志、异常类别和前端错误避免回显供应商完整错误体；但研究日志本身可能包含用户输入与数据，不能整体上传公开仓库。

## 本次公开仓库的发布范围

公开内容为应用源码、测试、版本化非秘密配置、依赖锁、Sphinx源文档和文档Actions。保留在本地的内容包括原始对话、已有运行数据库/trace、供应商配置、生成数据及truth.private目录、node_modules、虚拟环境和构建缓存。文档中的历史案例采用重新编写的汇总与明确局限，不嵌入完整私有session。

源码中的生成算法公开，因此任何能读仓库的agent都可以了解故障设定。要做独立科学评估，必须只把公开导出交给研究agent，并将场景构建者/提示作者与结果评审适当分离。仅把目录命名为private，不能证明严格盲评。

发布前由 `scripts/check_publication.py` 检查被Git跟踪的路径、明显凭据格式以及可选本地配置中的真实key是否出现在待发布内容；它只报告路径与规则，不打印secret。该扫描降低泄漏风险，不等于对所有类型敏感信息的形式化保证。
