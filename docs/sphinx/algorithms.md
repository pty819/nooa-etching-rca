# 研究算法、统计验证与因果边界

## 两条实现路径不能混写

**当前主路径**是 `autoresearch`：agent使用通用Python/Polars，自由实现筛选、关系特征、统计检验、OPLS/PCA或原始曲线实验。应用不预置一套保证正确的OPLS求解器，也没有承诺所有自由代码都被独立重算。

**保留的旧回归路径**是 `research/resume/finalize`：`Research`工具只允许raw/difference/ratio/product等因子，训练中位数填补、标准化、逻辑回归，开发集报告balanced accuracy和macro F1，冻结后才用test验收。它用于检查最早feature-only夹具和固定评估器，不能作为当前自由研究已使用的唯一算法。

## 先定义可比对象

一个研究量应能说明传感器语义、step边界、统计定义、单位、目标/参考腔、业务时段和独立lot。直接把时间点或同lot多片视为独立样本，会夸大显著性。先用目标腔比较识别候选，再用同期参考腔或同批基线检查共模，但应保留两腔固定硬件指纹。

差值、比值或跨step因子可以消除公共偏置，也可以制造伪关系。构造前要检查单位、分母接近零、step是否具有相同物理含义，以及预处理是否只在训练范围拟合。单列没有明显类别差异，不代表组合无用；组合预测有效，也不代表某部件因果已经识别。

## OPLS与PCA的正确定位

OPLS用于把与响应相关的预测方向与正交变异分开；不能把普通PLS、ANOVA或任意分类器改名为OPLS。自由实现必须对fit、transform和predict使用同一正交去除规则，并通过已知小型合成问题核对。历史agent确实写过训练期去正交、预测期遗漏变换的错误，后经专家审查修复；相关旧Q²必须撤回，不能择优保留。

PCA可帮助观察得分、聚类和异常，但若特征先按label监督筛选，随后同数据PCA分离只是描述。需要声称泛化性能时，筛选、缺失填补、标准化与估计器拟合均放入训练fold，开发/测试不反向参与选特征。最终保留集只承担事先冻结后的评估，不是不断调参的第二开发集。

## 效应量与小样本置换

两时段均值差应连同单位、独立批次分布、方向与不确定性报告。标准化效应可写作 $d=(\bar x_2-\bar x_1)/s_{pooled}$，小样本修正后为Hedges g。但当控制需求在异常时段被严格限幅，组内方差接近零时，标准化效应会极大；这首先提示平台/限幅现象，不意味着机械根因可信度也成千倍增加。

置换单位应与独立单位一致。有限随机置换不能把未命中写成p=0；可使用 $(b+1)/(B+1)$ 的有限次估计并说明抽样方式。若只有三个状态簇的三个均值，全部排列仅六个，双侧完全排序关联可能有2/6=1/3的精确p值，不能用渐近p≈0声称“剂量因果关系”。大量自适应筛选还涉及多重选择；一次FDR标记不自动校正整个研究过程的所有尝试。

## 原始曲线、稳态窗与反馈补偿

默认step均值包含开关和瞬态。例如prepare步骤背氦设定只有0与10Torr，整步均值约2.5不代表存在2.5Torr固定工况。研究应先按照实际setpoint段和联锁划窗，说明洗出比例、最少有效点及NaN/null处理，再比较稳态与过渡过程。

压力误差、流量需求与阀位可能属于同一个闭环；多条相关曲线不等于多份独立证据。双表同步也不能在取压与标定独立性未知时排除共因。温度控制接近设定值而加热功率变化，可能说明补偿，不能仅凭温度均值稳定就排除热相关问题。

## 维修响应的量化

相对正常基线的残留率和恢复率分别为：

$$r_{residual}=\frac{y_3-y_1}{y_2-y_1},\qquad
r_{recovery}=\frac{y_2-y_3}{y_2-y_1}.$$

两者在同一分母口径下相加为1，但可出现超调、负值或分母接近零。必须注明A-only还是A-B、分子分母、单位、所选lot和是否稳态量。历史研究把55.3%边缘残留误写为恢复，已在后轮纠正为44.7%恢复；不要把修订前后数字拼成一张看似一致的结论表。

## 从异常区域到部件根因

当前可接受的推理层级是：观测到什么 → 支持哪些关联 → 哪些机制兼容 → 哪项独立检查可区分。诊断结果不应跳过最后一步。源代码里的隐藏泄漏系数不能作为agent已经发现漏点的证据；保压检漏、独立标定、维修响应等未执行建议也不能写成已完成实验。

学术方案中的程序生成、候选记忆、结构去重和实验反馈可借鉴，但本项目没有复现CAAFE、LLM-FE或RD-Agent完整算法，也没有在真实工厂案例上与这些方法做对照基准。相关一手论文列于[参考材料](references.md)。
